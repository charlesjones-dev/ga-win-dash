# Support and Retirement

**Retired — September 2026.** GA Windows Dashboard is unmaintained and will receive no further maintenance, features, bug fixes, or security updates. All versions are unsupported.

Issues, pull requests, feature requests, and support requests are no longer accepted or triaged. There is no response-time commitment. See [SECURITY.md](SECURITY.md) for the retired security policy.

The source code, technical documentation, existing [MIT License](LICENSE), [changelog](CHANGELOG.md), lockfile, tags, and releases are retained for historical reference. Setup and build instructions describe the former project and are no longer maintained. Independent forks are welcome under the MIT License; their maintainers are responsible for their own support and security policies.
