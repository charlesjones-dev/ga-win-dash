# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-02-10

### Added

- Configurable grid layout (1-6 columns x 1-6 rows)
- Shared Google Analytics session via webview partition
- Per-cell address bars with URL validation
- Fullscreen mode hiding all UI chrome
- Keyboard shortcuts (Ctrl+R, Ctrl+Shift+F, Ctrl+,)
- Persistent URLs and window state across sessions
- Settings window with live grid reconfiguration
- Auto-update checker via GitHub Releases API
- Help > About dialog with version info
- Multiple distribution formats: portable .exe, NSIS installer, MSI package
- ESLint and Prettier for code quality
- Semgrep SAST and dependency audit scripts
- pnpm as package manager
